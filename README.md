# Research
A responsive, dependency-free VLSI Physical Design research workspace.

Features: physical design roadmap with official references, literature library, experiment log with WNS / area / power fields, research notebook, milestones, focus timer and daily motivational message.

Open index.html locally or serve it using GitHub Pages from the main branch root. All saved workspace data stays in the visitor's browser on their device. Export and restore JSON backups are available. No cloud sync, EDA execution or signoff validation is provided.

The motivational message changes automatically by the visitor's local calendar date, including when the page stays open. A curated set of 31 original messages rotates; no scheduled server or notification subscription is needed.

Reference sources: OpenROAD documentation, OpenROAD Flow Scripts tutorial, and OpenSTA documentation. External search links: Google Scholar, IEEE Xplore, arXiv.
