Before the next run
Placement & congestion research

Which placement parameter is changing? What is the baseline? Are design, constraints and measurement stage consistent? Which congestion and timing reports will you retain?

Clock tree & timing research

What clock and analysis assumptions are in use? What are the reported stage and corner? Are setup and hold observations recorded separately? How will you distinguish the clock effect from other changed variables?

Power, performance & area evaluation

Are area and power units explicit? What are the power-analysis assumptions? Are the library, voltage, input activity, extraction context and tool settings documented? Which trade-off matters for this experiment?

Reproducibility & publication readiness

Can another researcher reconstruct the run from the recorded inputs, versions and settings? Are limitations and contradictory results included? Are claims supported by the measured evidence?

From input to insight

Electronics & analog lab

Explore a circuit, vary its components and compare the expected output with your measurement.

Circuit workbench

Divider: R1 from input to output, R2 from output to ground. Op-amp: R1 to ground, R2 feedback. Filters use R1 and C. Filter input and output use the same amplitude convention.

Diagram & calculated output

Ideal, unloaded components. Op-amp output is a simple rail-clamped estimate; real output swing, bandwidth, offset, stability and loading require a device model. This workbench does not inspect arbitrary uploaded circuit images.

Divider and RC netlists can be simulated in ngspice. Op-amp netlist export is not provided because a real device model is needed.

Measured output check

Compares your measurement with this topology’s calculated output. It checks numerical agreement, not whether a real circuit is safe or correctly wired.

RC frequency sweep

Gain magnitude at 0.01× to 100× the cutoff frequency. Filters assume a zero-impedance source and no load.

Read the Analog Devices filter reference ↗

Digital input / output checker

Ideal Boolean logic. NOT uses input A only. Use Bit tools for multi-bit vector comparison and Python lab for custom test benches.

Quick checks, clear assumptions

Physical design helpers

Small calculations to support planning and research notes.

Clock frequency ↔ period

Period in ns = 1000 / frequency in MHz. This is a target conversion, not an achieved-frequency prediction.

Standard-cell core-area estimate

Approximate core area = standard-cell area / utilisation fraction. This simplified estimate excludes macros, channels, blockages, IO planning and other floorplan constraints.

How saving works

  • Your work is automatically saved in this browser on this device. Returning to this same website brings it back.
  • The saved workspace is separate from the public GitHub repository. Adding a paper does not commit it to GitHub or share it with anyone.
  • Another browser, another device, or private browsing has separate storage. Export here, then restore there to transfer your work.
  • Clearing browser data, browser storage eviction, or leaving a private session can remove saved work. A downloaded backup is the recovery copy.
  • This site does not provide a login or cloud database. Automatic cross-device sync is not currently available.
